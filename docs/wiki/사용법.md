# 사용법

## 방 만들기

1. `/rooms`에서 **+ 방 만들기** 클릭
2. 방 이름 입력
3. 비공개 방: 비밀번호 설정 (선택)
4. 생성 완료 → 자동 입장

---

## 방 참여하기

- **공개 방**: 목록에서 클릭 → 즉시 입장
- **비공개 방**: 클릭 → 비밀번호 입력 → 입장

---

## 음악 검색 & 추가

방에 입장한 후 검색 버튼(🔍)을 눌러 검색 모달을 엽니다.

### 쇼케이스 탭 (기본)

검색 없이 바로 곡을 선택할 수 있는 큐레이션 탭:

| 칩 | 내용 |
|---|---|
| 📊 차트 | YouTube 인기 플레이리스트 기반 (페이지네이션) |
| 🔥 인기곡 | 이 방에서 많이 재생된 곡 |
| 🎵 내 기록 | 내가 추가했던 곡 |
| ⏱ 최근 | 방 최근 재생 이력 |
| 💡 추천 | AI 추천 + 관련 곡 |

### 검색 탭

- 키워드 입력 → YouTube 검색 결과
- 자동완성 지원 (입력 시 제안)
- 무한 스크롤로 더 많은 결과

### URL 가져오기 탭

- YouTube URL 직접 붙여넣기
- 플레이리스트 URL → 곡 목록 표시 → 선택하여 추가

### 곡 선택 & 추가

1. 곡을 터치/클릭하여 선택 (여러 곡 동시 선택 가능)
2. 선택 순서가 번호로 표시됨
3. 하단 **추가** 버튼 → 큐에 등록

> 💡 일반 유저는 한 번에 최대 3곡, 호스트는 큐 최대치까지 추가 가능

## 재생 & 듣기

### 듣기 시작

**듣기** 버튼을 누르면 실시간 오디오 스트리밍이 시작됩니다. 모든 리스너는 동일한 시점을 동시에 듣습니다.

### 플레이어 기능

| 기능 | 설명 |
|------|------|
| ▶️ 듣기 토글 | 오디오 수신 시작/중지 |
| ⏭️ 스킵 | 호스트: 즉시 스킵 |
| 👍 투표 스킵 | 일반 유저: 과반수 투표 시 스킵 |
| 🔊 볼륨 | 볼륨 슬라이더 |
| 📺 Cast | Chromecast / AirPlay 전송 |
| 🎤 가사 | 실시간 동기화 가사 (자동 검색) |

### 가사

- 곡이 재생되면 자동으로 가사를 검색합니다
- 동기화 가사: 현재 재생 위치에 맞춰 하이라이트
- 번역: 설정된 언어로 자동 번역 (Gemini API 필요)

## 큐 관리

### 큐 목록

재생 대기 중인 곡 목록. 위에서부터 순서대로 재생됩니다.

| 조작 | 방법 |
|------|------|
| 순서 변경 | 드래그 앤 드롭 (호스트만) |
| 곡 제거 | 스와이프 또는 X 버튼 |
| 곡 정보 | 좋아요/싫어요 투표 |

### 재생 이력

이전에 재생된 곡 목록. 다시 큐에 추가할 수 있습니다.

## 채팅

방 참여자들과 실시간 대화:

- 일반 메시지 전송
- **@멘션**: `@닉네임`으로 특정 유저 호출 (푸시 알림 발송)
- **리액션**: 이모지 버튼으로 플로팅 리액션 전송
- **시스템 메시지**: 입장/퇴장/스킵 등 자동 표시

### 슬래시 커맨드

| 커맨드 | 기능 |
|--------|------|
| `/skip` | 투표 스킵 요청 |
| `/clear` | 채팅 기록 지우기 (본인만) |

---

## 방 설정 (호스트)

호스트는 방 설정 아이콘(⚙️)을 눌러 변경 가능:

- 방 이름 변경
- 비밀번호 설정/해제
- 멤버별 권한 조정
- 호스트 이전
- 멤버 강퇴

---

## 프로필 설정

프로필 아이콘 → 설정:

| 항목 | 설명 |
|------|------|
| 닉네임 변경 | 즉시 반영 |
| 비밀번호 변경 | 로컬 계정만 |
| Google 연동 | 기존 계정에 Google 로그인 추가 |
| 알림 설정 | 웹 푸시 이벤트별 on/off |
| 계정 삭제 | 되돌릴 수 없음 |
