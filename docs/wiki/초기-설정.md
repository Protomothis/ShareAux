# 초기 설정

## 첫 실행 — 관리자 계정 생성

처음 접속하면 3단계 설정 마법사가 표시됩니다:

### Step 1: 관리자 계정

| 항목 | 설명 |
|------|------|
| 아이디 | 영문/숫자 4~20자 |
| 비밀번호 | 8자 이상 |
| 닉네임 | 2~16자 (방에서 표시될 이름) |

이 계정이 **최고 관리자(SuperAdmin)** 가 됩니다. 초대코드 없이 생성됩니다.

### Step 2: 초대코드 생성 (선택)

다른 사용자를 초대하려면 코드를 생성합니다:
- 코드를 직접 입력하거나 자동 생성
- 최대 사용 횟수 설정 가능
- 나중에 어드민 페이지에서도 생성 가능 → **건너뛰기 가능**

### Step 3: 완료

설정이 끝나면 방 목록(`/rooms`)으로 이동합니다.

## Google OAuth 설정 (선택)

Google 로그인을 사용하려면:

### 1. Google Cloud Console에서 프로젝트 생성

1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 새 프로젝트 생성
3. **APIs & Services** → **OAuth consent screen** → External → 앱 이름/이메일 입력
4. **Credentials** → **Create Credentials** → **OAuth 2.0 Client ID**
5. Application type: **Web application**
6. Authorized redirect URIs에 추가:
   ```
   https://your-domain.com/api/auth/google/callback
   ```

### 2. ShareAux에 등록

**방법 A: .env 파일** (첫 실행 전)

```env
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-client-secret
GOOGLE_CALLBACK_URL=https://your-domain.com/api/auth/google/callback
```

**방법 B: 어드민 설정** (실행 후)

`/admin/settings` → 시크릿 섹션에서 직접 입력. 저장 즉시 반영됩니다.

## 환경변수 전체 목록

### 필수

| 변수 | 설명 | 예시 |
|------|------|------|
| `DB_PASSWORD` | DB 비밀번호 | `my-secure-password` |
| `JWT_SECRET` | JWT 서명 키 (랜덤 32자+) | `a8f3k2...` |
| `CLIENT_URL` | 클라이언트 접속 URL | `https://music.example.com` |

### 선택

| 변수 | 설명 | 미설정 시 |
|------|------|----------|
| `GOOGLE_CLIENT_ID` | Google OAuth | Google 로그인 비활성 |
| `GOOGLE_CLIENT_SECRET` | Google OAuth | Google 로그인 비활성 |
| `GOOGLE_CALLBACK_URL` | OAuth 콜백 URL | 기본 localhost |
| `GEMINI_API_KEY` | Gemini API | AI DJ + 번역 비활성 |
| `CAPTCHA_ENABLED` | PoW CAPTCHA | 기본 비활성 |

> 💡 대부분의 설정은 실행 후 어드민 페이지(`/admin/settings`)에서 변경 가능합니다.

## 로그인 방식

ShareAux는 3가지 로그인을 지원합니다:

| 방식 | 대상 | 특징 |
|------|------|------|
| **로컬 계정** | 주 사용자 | 아이디/비밀번호, 초대코드 필요 |
| **Google** | 주 사용자 | OAuth, 원클릭 로그인 |
| **게스트** | 임시 참여자 | 초대코드+닉네임만, 12시간 유효, 제한된 권한 |

### 권한 기본값

- **로컬/Google**: 듣기, 채팅, 리액션, 검색, 큐 추가, 투표 스킵
- **게스트**: 듣기만 (초대코드 설정으로 확장 가능)
