# ShareAux

> 🎶 셀프호스팅 실시간 음악 공유 플랫폼

방을 만들고, YouTube에서 음악을 검색하고, 모든 참여자에게 실시간으로 스트리밍합니다. 별도 음원 서비스 구독 없이 친구들과 함께 음악을 듣는 경험을 제공합니다.

## 주요 기능

- 🎵 **실시간 동기화 재생** — 모든 참여자가 같은 순간을 함께 듣습니다
- 🔍 **YouTube 검색** — 수천만 곡을 바로 검색하고 재생
- 🤖 **AI DJ** — Gemini 기반 자동 선곡 (분위기, 장르, 시대별)
- 📊 **차트** — YouTube 인기 플레이리스트 기반 음악 차트
- 💬 **실시간 채팅** — 음악을 들으며 대화
- 📱 **반응형 디자인** — 모바일, 태블릿, 데스크톱
- 🔐 **권한 시스템** — 초대코드, 게스트, 호스트별 권한
- 📺 **Cast 지원** — Chromecast, AirPlay로 외부 스피커 전송

## 기술 스택

```
Client (Next.js 16 / React 19) → NestJS API + WebSocket → yt-dlp → ffmpeg → 브라우저 (MSE)
```
