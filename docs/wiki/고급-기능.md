# 고급 기능

## AI DJ

큐가 비었을 때 자동으로 다음 곡을 선택해주는 기능입니다.

### 모드

| 모드 | 설명 |
|------|------|
| 🔀 관련곡 | 현재 곡과 비슷한 곡 |
| 📻 라디오 | 라디오 스타일 선곡 |
| 📜 히스토리 | 방에서 이전에 재생된 곡 위주 |
| 🔥 인기곡 | 전체 방에서 가장 많이 재생된 곡 |
| 🎲 믹스 | 여러 소스 혼합 |
| ❤️ 즐겨찾기 | 방 멤버들의 즐겨찾기 기반 |
| 🤖 AI | Gemini API 기반 큐레이션 |
| 📊 차트 | 차트 인기곡 기반 |

### 태그 필터 (AI 모드)

AI 모드에서는 세밀한 취향 조절이 가능합니다:

- **분위기**: 잔잔한, 신나는, 감성적, 몽환적, 에너지틱 등 11종
- **장르**: 인디, 팝, 힙합, R&B, 록, 일렉, 재즈 등 15종
- **시대**: 최신, 2010년대, 2000년대, 90년대, 80년대 등
- **국가**: 🇰🇷🇯🇵🇺🇸🇬🇧🇫🇷🇧🇷🇪🇸🇸🇪🇨🇳🇦🇺🇮🇳
- **성향**: 대중적 ↔ 언더그라운드 (슬라이더)

### 후보 관리

AI DJ가 제안한 다음 곡 후보를 미리 볼 수 있습니다:

- **핀**: 이 곡을 반드시 다음에 재생
- **스킵**: 후보에서 제거
- **큐에 추가**: 지금 바로 큐에 넣기
- **새로고침**: 새 후보 생성

> 💡 AI 모드는 어드민이 Gemini API 키를 설정해야 활성화됩니다.

## 차트

YouTube 인기 플레이리스트 기반 음악 차트입니다.

### 특징
- 매일 자동 갱신 (기본 04시)
- 카테고리별 탭 (한국, 글로벌 등)
- 상위 5곡은 카드 형태로 강조 표시
- 20곡 단위 페이지네이션
- 곡 클릭으로 바로 큐에 추가 가능

### 차트 소스 커스터마이징

어드민 설정에서 차트 플레이리스트를 변경할 수 있습니다:

```json
[
  { "name": "한국 인기", "emoji": "🇰🇷", "playlistId": "PLxxxxxx" },
  { "name": "글로벌 TOP", "emoji": "🌍", "playlistId": "PLyyyyyy" }
]
```

## 즐겨찾기

자주 듣는 곡을 저장하고 관리할 수 있습니다.

### 기능
- **폴더**: 카테고리별 분류 (색상 지정 가능)
- **정렬**: 최신순, 오래된순, 이름순, 아티스트순
- **검색**: 이름/아티스트로 필터링
- **편집 모드**: 복수 선택 → 일괄 삭제 / 폴더 이동
- **드래그 앤 드롭**: 폴더 간 이동

### 곡 추가 방법
1. 검색 결과에서 ❤️ 버튼
2. 큐에서 ❤️ 버튼
3. URL 가져오기에서 "즐겨찾기에 저장"

> 💡 게스트 계정은 즐겨찾기를 사용할 수 없습니다.

## 웹 푸시 알림

방에서 나와있을 때도 중요한 이벤트를 알려줍니다.

### 알림 종류

| 이벤트 | 설명 |
|--------|------|
| 새 곡 시작 | 다음 곡이 재생될 때 |
| 투표 스킵 통과 | 스킵 투표가 통과됐을 때 |
| 호스트 변경 | 호스트가 바뀌었을 때 |
| 강퇴 | 방에서 강퇴당했을 때 |
| 멘션 | 채팅에서 @멘션되었을 때 |

### 설정

프로필 → 알림 설정에서 이벤트별로 on/off 가능.

### 요구사항
- HTTPS 연결 필수 (localhost 제외)
- 브라우저 알림 허용 필요
- 어드민이 VAPID 키 설정 (자동 생성됨)

## Cast (Chromecast / AirPlay)

외부 스피커로 오디오를 전송할 수 있습니다.

### 사용법
1. 플레이어의 Cast 버튼 클릭
2. 사용 가능한 기기 선택
3. 오디오가 선택한 기기에서 재생됨

### 요구사항
- HTTPS 연결 필수
- 같은 네트워크에 Cast 기기가 있어야 함
- 브라우저에서 Cast 기능 지원 (Chrome, Edge, Safari)

## 투표 시스템

### 스킵 투표
- 일반 유저가 스킵 요청 → 리스너의 과반수 투표 시 스킵
- 호스트는 즉시 스킵 가능

### 트랙 투표
- 👍 좋아요 / 👎 싫어요
- 방 내에서 트랙 인기도 파악
- 어드민 대시보드에서 전체 통계 확인 가능
