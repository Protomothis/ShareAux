# 설치 가이드

## 빠른 시작 (5분)

### 1. 저장소 클론

```bash
git clone https://github.com/Protomothis/ShareAux.git
cd ShareAux
```

### 2. 환경변수 설정

```bash
cp .env.example .env
```

`.env` 파일을 열고 **반드시** 수정해야 할 값:

```env
# 필수 — 반드시 변경하세요
JWT_SECRET=여기에-랜덤한-긴-문자열-입력
DB_PASSWORD=안전한-데이터베이스-비밀번호

# 외부 접속 시 실제 URL로 변경
CLIENT_URL=http://localhost:8080
```

### 3. 실행

```bash
docker compose up -d
```

### 4. 접속

브라우저에서 `http://localhost:8080` 접속 → 자동으로 초기 설정 화면으로 이동합니다.

## 프로덕션 배포

### 도메인 + HTTPS 설정

`Caddyfile`을 수정하여 도메인을 설정하면 Caddy가 자동으로 Let's Encrypt 인증서를 발급합니다:

```
your-domain.com {
    handle /api/* {
        reverse_proxy shareaux-server:3000
    }
    handle /ws {
        reverse_proxy shareaux-server:3000
    }
    handle {
        reverse_proxy shareaux-client:3001
    }
}
```

`docker-compose.yml`의 gateway 포트를 변경:

```yaml
ports:
  - '443:443'
  - '80:80'  # HTTP → HTTPS 리다이렉트용
```

`.env`의 `CLIENT_URL`도 업데이트:

```env
CLIENT_URL=https://your-domain.com
```

### GHCR 이미지 사용 (빌드 생략)

직접 빌드 대신 미리 빌드된 이미지를 사용할 수 있습니다:

```yaml
# docker-compose.yml의 server/client를 수정
server:
  image: ghcr.io/protomothis/shareaux-server:latest
  # build: ./server  ← 주석 처리

client:
  image: ghcr.io/protomothis/shareaux-client:latest
  # build: ./client  ← 주석 처리
```


## 업데이트

```bash
# 최신 코드 받기
git pull

# 이미지 재빌드 + 재시작
docker compose up -d --build

# GHCR 이미지 사용 시
docker compose pull && docker compose up -d
```

## 데이터 백업

PostgreSQL 데이터는 Docker 볼륨 `pgdata`에 저장됩니다:

```bash
# 백업
docker exec shareaux-db pg_dump -U spotiparty spotiparty > backup.sql

# 복원
docker exec -i shareaux-db psql -U spotiparty spotiparty < backup.sql
```

## 제거

```bash
docker compose down        # 컨테이너만 제거
docker compose down -v     # 컨테이너 + DB 데이터 제거 (주의!)
```
