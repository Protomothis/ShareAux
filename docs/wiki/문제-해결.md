# 문제 해결

## 설치 / 실행

### Docker Compose가 실행되지 않아요

```bash
# Docker 데몬 실행 확인
docker info

# 포트 충돌 확인
lsof -i :8080
lsof -i :5432
```

### DB 연결 실패 (서버 로그에 `ECONNREFUSED`)

DB가 준비되기 전에 서버가 시작된 경우:

```bash
docker compose down
docker compose up -d
```

`docker-compose.yml`의 healthcheck가 DB 준비를 보장하지만, 첫 실행 시 이미지 빌드 시간 때문에 타이밍 이슈가 발생할 수 있습니다.

### `/setup` 화면이 안 나와요

이미 유저가 1명이라도 있으면 setup은 건너뜁니다. DB를 초기화하려면:

```bash
docker compose down -v   # 주의: 모든 데이터 삭제
docker compose up -d
```

## 오디오 / 재생

### 소리가 안 들려요

1. **듣기 버튼**을 눌렀는지 확인 — 입장만으로는 오디오가 시작되지 않습니다
2. 브라우저 볼륨 + 시스템 볼륨 확인
3. 브라우저의 자동재생 정책: 처음 한 번은 반드시 사용자 클릭으로 시작해야 합니다

### 재생이 끊겨요 (버퍼링)

- 네트워크 상태 확인 (최소 200kbps 안정적 연결 필요)
- 어드민 설정에서 비트레이트 낮추기 (160kbps → 128kbps)
- 동시 리스너가 많은 경우 서버 대역폭 확인

### 특정 곡이 재생되지 않아요

- YouTube에서 지역 제한이 걸린 곡일 수 있습니다
- 연령 제한 영상은 재생 불가
- 라이브 스트리밍은 지원하지 않습니다
- 서버에서 yt-dlp가 최신 버전인지 확인

## WebSocket / 연결

### "연결 끊김" 배너가 계속 나와요

- 서버가 정상 실행 중인지 확인: `docker logs shareaux-server`
- 방화벽이 WebSocket을 차단하는 경우 (프록시 설정 확인)
- Caddy가 정상인지: `docker logs shareaux-gateway`

### 다른 기기에서 접속하면 기존 연결이 끊겨요

정상 동작입니다. ShareAux는 **1인 1방** 정책:
- 한 계정으로 동시에 하나의 방만 참여 가능
- 다른 방/기기에서 접속하면 이전 연결은 종료됩니다 (코드 4007/4008)

## 인증

### Google 로그인이 안 돼요

1. 어드민 설정에서 Google Client ID/Secret이 올바른지 확인
2. Callback URL이 실제 도메인과 일치하는지 확인
3. Google Cloud Console에서 승인된 리다이렉트 URI 확인

### 게스트가 로그인할 수 없어요

- 어드민 설정에서 "게스트 로그인"이 활성화되어 있는지 확인
- 초대코드가 유효한지 (만료/비활성화/사용 횟수 초과)

### 비밀번호를 잊었어요 (관리자)

현재 비밀번호 재설정 기능이 없습니다. DB에 직접 접근하여 초기화:

```bash
docker exec -it shareaux-db psql -U spotiparty -d spotiparty
```

```sql
-- 유저 확인
SELECT id, username FROM "user" WHERE role = 'superAdmin';

-- 비밀번호 리셋 (bcrypt 해시로 설정 필요)
-- 또는 DB 초기화 후 재설정이 더 간단합니다
```

## 가사 / 번역

### 가사가 안 나와요

- 모든 곡에 가사가 있는 것은 아닙니다
- 가사 검색 실패 시 24시간 후 자동 재시도
- 서버에 `python3`과 `syncedlyrics` 패키지가 설치되어 있어야 합니다 (Docker 이미지에 포함)

### 번역이 안 돼요

- 어드민 설정에서 Gemini API 키가 설정되어 있는지 확인
- 일일 번역 한도 초과 여부 확인 (기본 200회/일)

## 성능

### 메모리 사용량이 높아요

정상입니다. 각 활성 방마다:
- ffmpeg 프로세스 (~30MB)
- 프리로드 버퍼 (최대 50MB)
- WS 연결 상태

어드민 대시보드에서 실시간 확인 가능.

### CPU 사용량이 높아요

ffmpeg 인코딩이 CPU를 사용합니다. 동시 활성 방 수에 비례합니다:
- 1~3방: 1코어로 충분
- 5~10방: 2코어+ 권장

## 기타

### 알림이 안 와요

1. 브라우저에서 알림 허용했는지 확인
2. HTTPS 연결인지 확인 (localhost는 예외)
3. 프로필 → 알림 설정에서 해당 이벤트가 활성인지 확인

### 차트가 비어있어요

- 어드민 설정에서 차트가 활성화되어 있는지 확인
- 첫 실행 후 차트 갱신까지 대기 (또는 서버 재시작 시 즉시 수집)
- 플레이리스트 ID가 유효한지 확인

로그인 화면 또는 방 내에서 언어 선택 가능:
- 🇰🇷 한국어
- 🇺🇸 English
