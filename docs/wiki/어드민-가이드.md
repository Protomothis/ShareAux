# 어드민 가이드

> 어드민 페이지는 `/admin`에서 접근합니다. Admin 또는 SuperAdmin 역할이 필요합니다.

## 대시보드

한눈에 서버 상태를 파악:

- **통계**: 유저 수, 활성 방 수, 전체 방 수
- **서버 리소스**: ffmpeg 프로세스, 프리로드 메모리, 힙 사용량, 업타임
- **차트**: 접속자 추이 (1h/6h/24h), 메모리 사용량, 일일 재생 횟수
- **유저 분포**: provider별, role별 시각화

---

## 유저 관리

### 유저 목록
- 검색, role/provider/status 필터
- 페이지네이션

### 가능한 작업

| 작업 | 설명 | 대상 |
|------|------|------|
| 역할 변경 | User ↔ Admin | SuperAdmin 제외 |
| 권한 수정 | 개별 Permission 설정 | 전체 |
| 밴 | 접속 차단 + WS 종료 | 전체 |
| 언밴 | 차단 해제 | 밴된 유저 |
| 삭제 | 영구 삭제 | 전체 |

## 초대코드 관리

| 기능 | 설명 |
|------|------|
| 생성 | 코드 직접 지정 또는 자동 생성, 사용 한도, 만료일, 권한 설정 |

## 시스템 설정

`/admin/settings`에서 실시간으로 변경 가능. 저장 즉시 반영됩니다.

### 인증

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 게스트 로그인 | 활성 | 초대코드+닉네임으로 임시 입장 |
| Google 로그인 | 활성 | OAuth 시크릿 필요 |
| 게스트 유효 시간 | 12시간 | 1~720시간 |
| CAPTCHA | 비활성 | PoW 방식 봇 방지 |

### 방

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 방 최대 인원 | 20명 | 2~100 |
| 유저당 방 생성 한도 | 3개 | 1~10 |

### 큐

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 1인당 큐 한도 | 10곡 | 1~50 |
| 트랙 최대 길이 | 10분 | 1~60 |

### AutoDJ

| 설정 | 기본값 | 설명 |
|------|--------|------|
| AutoDJ 활성 | 활성 | 자동 선곡 기능 |
| AI DJ | 활성 | Gemini 기반 (API 키 필요) |
| AI 모델 | gemini-2.5-flash-lite | 모델 선택 |
| 배치 크기 | 10 | 한 번에 생성할 후보 수 |
| 온도 | 0.7 | 높을수록 다양, 낮을수록 안정 |

### 스트리밍

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 비트레이트 제한 | 비활성 | 대역폭 절약용 |
| 최대 비트레이트 | 160kbps | 64~320 |

### 번역 (가사)

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 번역 기능 | 활성 | Gemini API 키 필요 |
| 일일 한도 | 200회 | API 비용 제한 |
| 번역 모델 | gemini-2.5-flash-lite | 모델 선택 |
| 대상 언어 | 한국어 | 번역할 언어 |

### 차트

| 설정 | 기본값 | 설명 |
|------|--------|------|
| 차트 기능 | 활성 | YouTube 플레이리스트 기반 |
| 갱신 시각 | 04시 | 매일 자동 갱신 |
| 플레이리스트 | (기본 목록) | JSON 형식 |

### 시크릿 (암호화 저장)

| 키 | 용도 |
|---|---|
| Google Client ID/Secret | Google 로그인 |
| Google Callback URL | OAuth 콜백 |
| Gemini API Key | AI DJ + 번역 |
| VAPID Public/Private Key | 웹 푸시 (자동 생성) |

## IP 차단

- 악의적 접근 IP 수동 차단
- 만료일 설정 가능 (영구 또는 기간 한정)
- WS flood 감지 시 자동 차단 (30분 → 24시간 에스컬레이션)

## 데이터 정리

디스크/DB 관리를 위한 정리 도구:

| 항목 | 설명 |
|------|------|
| 미재생 트랙 | 한 번도 재생되지 않은 트랙 삭제 |
| 오래된 트랙 | 30일 이상 미재생 트랙 |
| 재생 이력 | 30일 이상 경과 이력 |
| 비활성 방 | 7일 이상 비활성 |
| 빈 방 | 멤버 없는 비활성 방 |
| 만료 게스트 | 12시간 경과 게스트 계정 |
| 비활성 게스트 | 30일 이상 미활동 게스트 |

각 항목 옆에 대상 건수가 표시되며, 버튼으로 실행합니다.

## 모니터링

### 감사 로그
관리 행위 자동 기록: 설정 변경, 역할 변경, 밴/언밴, IP 차단, 신고 처리

### 에러 로그
- 실시간 탭: 메모리에 보관 (서버 재시작 시 소멸)
- 파일 탭: 영구 기록
- HTTP 상태, 경로, 메시지, 스택트레이스 확인

### 신고 관리
유저가 제출한 신고를 확인하고 처리 (resolved / dismissed)
